# venture_toolkit — 案例工具箱

## 三件套

1. **intake 流程**：复制 ventures/_template/ → 填四必填（假设/止损线/最小验证预算/点子来源）→ cockpit/status.md 挂灯 → 若属开新线（L3）先写 grill-record
2. **上架物料模式**：listing-{渠道}.md（标题/一句话简介/描述/定价 rationale/冷启动分发/风险注意）+ 交付物 build 脚本模式（案例1 的 dist/ 流程）
3. **记账复盘模式**：案例 ledger.md（日期/事件/金额/渠道必填）+ 周五蒸馏动作（≥1 条 knowledge 或记"无可蒸馏"）
