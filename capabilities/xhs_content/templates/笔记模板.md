# 笔记模板（xhs_content 直写作业结构）

> 配合 playbooks/内容生产规范.md 使用。复制到案例 content/ 目录填。

```markdown
# {主题}笔记草稿 — {日期}

## 【标题候选】（3-4 个，套标题四公式）
1.
2.

## 【封面】
- 大字标题（≤8 字）：
- 钩子小字：
- 配色主题：warm_grey/twilight/crimson/mist/cool/warm/blank

## 【正文】
（翻车真事开场 3 行 → 方法/可带走的资产 → 金句）
✍️【真人改写槽位1：真实经历+真实耗时——发布前必替换】

## 【金句】（海报级短句，≤20 字）

## 【互动钩子】（扣字式提问）

## 【话题标签】（3-5 个场景词，禁泛词）

## 【发布自查】
- [ ] ✍️ 槽位已替换
- [ ] 勾选「AI 辅助创作」标注
- [ ] 无外链/微信号/谐音引流（转化走评论区→私信）
- [ ] 有可带走的资产（清单/模板/步骤）
- [ ] 数据/事例真实可回溯
```
