# 从零到万粉 · 操作手册

> 你不需要懂代码，只需要按下面 4 步循环跑。每次产笔记就走一遍这个循环。
> 核心真相：**万粉 = 爆款 × 量 × 持续**，不是单篇完美。先跑通闭环拿到真实数据，再靠数据复刻放大。
> 所有命令都用 `python xhs.py <动作>`，中文触发词，不用记脚本名。

---

## 0. 一次性准备（只做一次）

```bash
# 1. 确认 .env 已填好 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL（已就绪）
# 2. 确认字体在 assets/fonts/（已就绪）
# 3. 首次登录小红书创作者端（发布用）—— 小红书 APP 扫码
python xhs.py 登录
```

⚠️ 首次扫码后 Cookie 存到 `.cache/`，后续复用，过期会自动提示重扫。
采集数据用的 PC 端登录（`xhs.py 采集` 时会自动触发，也可单独 `python xhs.py 登录 PC`）。

## 1. 四步循环（每次产笔记就跑一遍）

记忆口诀：**生成 → 审核 → 发布 → 采集**

### ① 生成 → `docs_agent/approved/`（B级以上自动进）

```bash
python xhs.py 生成
```

启动 Streamlit 工作台 → 浏览器打开 `http://localhost:8501` → 「📚选题池」tab：
- 顶部「🔍筛选选题」按状态/支柱/公式/关键词筛
- 每个选题行有「✍️生成笔记」按钮，点哪个生成哪个
- 或「⚙️批量生成」设篇数批量生成，或「🧠智能推荐并生成」一键选最优

生成期间页面显示实时日志（能看到当前在哪个 Agent、第几轮）。系统自动完成：7 Agent 协作 → 写正文 → 做封面+内页 → 审核（最多5轮迭代）→ 生成预设评论。**B级以上笔记自动进 approved/，C级留「📝待审核」tab 人工处理。**

### ② 审核 → `docs_agent/approved/`

在工作台「📝待审核笔记」tab（只装C级差笔记，平时基本空）。好笔记已在 approved/，无需手动。

### ③ 发布 → `docs_agent/published/`

```bash
python xhs.py 发布
```

复用已存 Cookie，自动发布 approved/ 笔记到小红书，URL 写回 `note.md`，目录迁到 `published/`。
也可在工作台「🚀一键发布助手」tab 勾选发布。

> ⚠️ 如果发布显示"成功"但小红书后台看不到，多半是 Cookie 过期，先 `python xhs.py 登录` 刷新再发。

### ④ 复盘 → 数据回流（发布后隔 24-48 小时）

```bash
python xhs.py 采集
```

自动串起三步：登 PC 端 → 采集已发布笔记真实点赞收藏 → 竞品爆款分析灌进选题池。
系统自动算 S/A/B/C 等级，更新 `performance.json`，最近 3 篇全 C 级触发**熔断**。

## 2. 万粉节奏（关键）

| 阶段 | 目标 | 动作 |
|---|---|---|
| **第 1 周** | 跑通闭环 | `xhs.py 生成`→审核→`xhs.py 发布`→`xhs.py 采集`，发 5 篇，采真实数据 |
| **第 2-3 周** | 找爆款方向 | 看数据：哪个**系列**、哪种**标题公式**、哪个**支柱赛道**数据最好 → 倾斜生产 |
| **第 4 周起** | 放大复刻 | `xhs.py 采集` 自动把爆款选题灌进选题池，稳定每周 4-5 篇 |
| **持续** | 日更/隔日更 | 小红书算法奖励活跃度。断更 3 天流量掉得很快 |

⚠️ **熔断**：连续 3 篇 C 级，**立刻停**，去工作台「📈数据复盘」tab 看问题，换选题方向。

## 3. 全部命令速查

```bash
python xhs.py              # 显示帮助菜单
python xhs.py 生成 [N]     # 启动工作台；或「生成 3」直接生成第3篇
python xhs.py 批量 [N]     # 批量生成 N 篇（默认3）
python xhs.py 发布 [N]     # 发布笔记（N=篇数）
python xhs.py 采集         # 采集互动数据 + 竞品灌选题池
python xhs.py 竞品 [词]    # 只做竞品分析（可带搜索词，如「独居女生」）
python xhs.py 登录         # 登录创作者端；「登录 PC」登录采集端
python xhs.py 诊断         # 账号诊断
python xhs.py 评论         # 抓取评论区洞察
python xhs.py 复刻 [URL]   # 复刻爆款笔记
python xhs.py 列表         # 列出选题池
```

## 4. 怎么判断一篇"完美"笔记（看这 4 点）

1. **封面**：大字标题一眼能读懂情绪，配色和情绪匹配。看不清字或塑料感 → 重生成。
2. **标题**：用了 4 种公式之一（问句式/概念解读式/观点冲击式/方法承诺式），有钩子。
3. **正文**：陪伴感，像闺蜜夜聊，**不要**理性分析和下定义。结尾有系列引导（追更感）。
4. **标签**：3-5 个精准标签（代码已兜底，不会出现 #情感 这种泛词）。

系统已把这 4 点的概率拉满。你审核时只需做最后一道人工判断：像不像真人写的、封面想不想点。

## 5. 一句话记住

**先跑通闭环拿到真实数据，比优化任何代码都重要。** 你现在 `performance.json` 全是 0，系统是盲的。发第一篇真笔记、`xhs.py 采集` 采集真实数据，是当前唯一最高优先级的事。
