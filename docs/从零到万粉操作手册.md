# 从零到万粉 · 操作手册

> 你不需要懂代码，只需要按下面 4 步循环跑。每次产笔记就走一遍这个循环。
> 核心真相：**万粉 = 爆款 × 量 × 持续**，不是单篇完美。先跑通闭环拿到真实数据，再靠数据复刻放大。

---

## 0. 一次性准备（只做一次）

```bash
# 1. 确认 .env 已填好 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL（已就绪）
# 2. 确认字体在 assets/fonts/（已就绪）
# 3. 首次登录小红书创作者端（发布用）—— 小红书 APP 扫码
python scripts/xhs_auth_helper.py --creator
```

⚠️ 首次扫码后 Cookie 存到 `.cache/xhs_creator_cookie.json`，后续复用，过期会自动提示重扫。
PC 端登录（采集数据用）发布前不用急，采集数据时再登：
```bash
python scripts/xhs_auth_helper.py --pc
```

## 1. 四步循环（每次产笔记就跑一遍）

### ① 生成 → `docs_agent/pending/`

```bash
# 单篇（按选题池编号）
python pipeline.py --index 0

# 批量生成（推荐，一次攒一批）
python pipeline.py --batch --max 5

# 或交互式菜单（最省心）
python start.py
```

系统会自动：7 个 Agent 协作 → 写正文 → 做封面 + 内页 → 审核（最多 5 轮迭代）→ 生成预设评论。
产出在 `docs_agent/pending/{选题名}_{hash}/`，含 `note.md` + `cover_ai.png` + `inner_page_*.png`。

### ② 审核 → `docs_agent/approved/`

```bash
streamlit run app.py
```

打开浏览器 → **📝待审核** tab：
- 肉眼看封面 + 正文，像不像闺蜜夜聊（陪伴感，不要分析腔）。
- 看着可以 → 点 **✅ 通过** → 自动迁移到 `approved/`。
- 不满意 → 点「重生成」或直接删目录，不要发烂笔记。

### ③ 发布 → `docs_agent/published/`

两种方式二选一：

**A. UI 发布（推荐）**：app.py → **🚀一键发布助手** tab → 勾选 approved 笔记 → 点发布。
**B. 命令行发布**：
```bash
python scripts/auto_publish.py --dry-run     # 先预览要发哪些（不登录不发布）
python scripts/auto_publish.py --limit 3     # 实际发布，最多 3 篇
```

发布成功后 URL 写回 `note.md`，目录迁移到 `published/`。

### ④ 复盘 → 数据回流

发布后 **隔 24-48 小时**（让笔记积累真实互动）再采集：
```bash
python scripts/fetch_performance.py          # 采集 published/ + archived/ 的真实点赞收藏评论
```

系统自动：算每篇 S/A/B/C 等级 → 更新 `data/performance.json` → 最近 3 篇全 C 级触发**熔断**（侧边栏红字警告，暂停发布，逼你复盘选题）。

**爆款反哺选题**：
```bash
python scripts/competitor_analysis.py --save              # 搜情感赛道爆款，分析后灌进选题池
python scripts/competitor_analysis.py --query "你的细分词" --save
```

## 2. 万粉节奏（关键）

| 阶段 | 目标 | 动作 |
|---|---|---|
| **第 1 周** | 跑通闭环 | 生成→审核→发布→复盘，发 5 篇，采集真实数据。哪怕数据差也要采，让系统"睁眼" |
| **第 2-3 周** | 找爆款方向 | 看数据：哪个**系列**、哪种**标题公式**、哪个**支柱赛道**数据最好 → 倾斜生产 |
| **第 4 周起** | 放大复刻 | 把爆款选题用 `competitor_analysis.py --save` 灌进选题池，复刻同款，稳定每周 4-5 篇 |
| **持续** | 日更/隔日更 | 小红书算法奖励活跃度。断更 3 天流量掉得很快 |

⚠️ **熔断**：如果连续 3 篇 C 级，**立刻停**，不要硬发。去 📈数据复盘 tab 看问题，换选题方向。

## 3. 怎么判断一篇"完美"笔记（看这 4 点）

1. **封面**：大字标题一眼能读懂情绪，配色和情绪匹配（愤怒→crimson，正义→mist）。看不清字或塑料感 → 重生成。
2. **标题**：用了 4 种公式之一（问句式/概念解读式/观点冲击式/方法承诺式），有钩子让人想点。
3. **正文**：陪伴感，像闺蜜夜聊，**不要**理性分析和下定义。结尾有系列引导（追更感）。
4. **标签**：3-5 个精准标签（代码已兜底，不会出现 #情感 这种泛词）。

系统已经把这 4 点的概率拉满了（审核迭代 + 代码兜底 + 思考链拦截）。你审核时只需做**最后一道人工判断**：像不像真人写的、封面想不想点。

## 4. 常见问题

| 问题 | 解决 |
|---|---|
| `tmp*` 空目录污染审核界面 | 删掉 `docs_agent/approved/tmp*` 和 `docs_agent/_rejected/` 里的废笔记 |
| 发布报 Cookie 过期 | `python scripts/xhs_auth_helper.py --creator` 重新扫码 |
| 采集数据全是 0 | 笔记发布时间太短，小红书数据有延迟，等 24-48h 再采 |
| 想换选题方向 | 编辑 `data/topics.json`，或 `competitor_analysis.py --query "新方向" --save` |
| 想看哪类笔记最火 | app.py → 📈数据复盘 tab，看公式/支柱分析 |

---

## 5. 一句话记住

**先跑通闭环拿到真实数据，比优化任何代码都重要。** 你现在 `performance.json` 全是 0，系统是盲的。发第一篇真笔记、采集真实数据，是当前唯一最高优先级的事。
