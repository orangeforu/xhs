# 出海产品选品调研 — 2026-09-29

> 背景：小红书项目转向被动收入路线（详见 2026-09-28 讨论）。锁定：线 A（数字资产上架，快速验证"资产复购"模式）+ 线 B（Chrome 插件/micro-SaaS，主攻方向）。
> 本文只收录带证据的结论，不收录灵感。

## 一、市场信号汇总

### 信号 1：通用 prompt 包已死，niche + 工作流捆绑是赢家（线 A 定位依据）

- Gumroad/Etsy 数据：同质化 "500+ ChatGPT Prompts for Business" 只能卖 **$3-7**；赢家是**面向具体职业的捆绑包**（prompts + Notion 模板 + PDF + SOP）
- Etsy 畅销品类分析：All-in-One Business Starter Bundles、Niche E-commerce/Seller Toolkits 领跑——**卖给"正在赚钱的人"（卖家/自由职业者）比卖给上班族转化更好**
- PromptBase 顶部卖家 $1500+/月（单条 $3-15）——天花板存在但不高
- **结论**：线 A 必须带差异化钩子。我们的钩子 =「提示词 + 防 AI 编造核对清单 + 翻车点」，源自小红书项目实测洞察（"AI 编的不是内容，是逻辑"）——搜到的竞品没人做 QA 层

### 信号 2：Chrome 插件一次性买断 $9-69 可行，但"脉冲式"收入（线 B 依据）

- PR review 插件 $9.50 一次性买断，日活工具（dev.to 2026-07 实例）
- Tailscan（Tailwind 审查工具）转一次性买断后峰值 $30K/月，随后回落至 $3.3K MRR 水位——**一次性买断 = 上架脉冲 + 长尾平台期**，符合"半被动"预期
- 老案例：$69 一次性买断累计 ~$100K（IndieHackers）
- **结论**：插件路线成立，选品要选"每天打开的页面上的具体摩擦"

### 信号 3：boring 垂直 niche 是 solo founder 最稳的 MRR 来源（线 B 升级方向）

- 实例：一人服务 200 家制服租赁公司 × $250/月 ≈ $50K MRR——"听起来离谱"的 niche 最肥
- 共识："stop thinking like a developer"——**付费者不是开发者，是用水管的修水管的人**
- $3K MRR 低维护产品 > $12K MRR 需要投流消费级产品
- **结论**：线 B 不要做"给程序员的工具"（我们自己就是程序员，会被自己的需求误导），要找非软件行业的工作流摩擦

## 三、线 A 产品定义（本日已启动）

**产品**：The 9-to-5 AI Workflow Kit（办公室 AI 工作流包）
**人群**：企业非技术岗（ops/PM/行政/财务）——另注意信号 1 的警告：此人群转化弱于"卖家人群"，v2 可考虑出 "for Freelancers/Etsy Sellers" 变体
**差异化**：每条工作流 = 提示词 + 输入准备法 + **防编造核对清单** + 已知翻车点 + 耗时对比。竞品只有 prompt 清单
**定价**：免费样张（1 条工作流）引流 → 全套 $9（8-10 条）
**上架**：Gumroad 首发，Payhip/Etsy 二次铺货（零边际成本）
**止损**：上架 4 周内 <10 次付费下载 → 不加 SKU，转 B1
