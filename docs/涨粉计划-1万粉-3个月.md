## 1. 三阶段计划（每阶段有通过门槛，达不到就调整）

### 🩺 阶段 1：账号诊断与修复（第 1-2 周）

**目标：找出 0 涨粉的根因，让账号恢复正常推荐。**

#### 任务 1.1 限流自检（人工操作，半天）
登录小红书创作服务平台（creator.xiaohongshu.com），逐项核对：

- [ ] **账号违规记录**：设置 → 账号与安全 → 看有无违规通知、限流通知
- [ ] **单篇诊断**：挑 3 篇近期笔记看「数据分析」→ 如果"曝光"骤降或为 0，确认被限流
- [ ] **内容审核状态**：看是否有笔记处于"审核中"或"仅自己可见"
- [ ] **原创声明**：是否开了原创保护（影响推荐权重）

#### 任务 1.2 AI 痕迹清洗（系统改造 + 人工）
你的内容 AI 味特征明显，疑似触发平台 AI 检测：

- **特征**：三段式结构、emoji 规律（💔✨👇）、金句收尾、排版过度整齐
- **改造**：
  - [ ] 人工润色 AI 初稿（系统产出 A 级后，人工改写 30%：替换生硬比喻、打乱结构、加口语化"废话"、去掉规律性 emoji）
  - [ ] 调整 `prompts/agent_writer.md`：降低结构化指令，增加"像真人发朋友圈的随意感"要求
  - [ ] 标题去掉"模板感"（如"3步识别""5个信号"太工整，改成口语化）

#### 任务 1.3 发布节奏修复
- [ ] 改为**固定时间日更或隔日更**（建议晚 8-10 点），不要批量发布
- [ ] 单日不超过 1 篇，避免触发"营销号"风控
- [ ] 发布后 30 分钟内自评 + 回复前几条评论（提升初始互动权重）

#### ✅ 阶段 1 通过门槛
连续 **7 篇新笔记**，满足以下任一即视为账号恢复：
- 单篇曝光突破 **2,000**（现为 327）
- 单篇互动率突破 **2%**
- 出现 1 篇点赞 ≥50 的笔记

**若 2 周后仍达不到 → 考虑阶段 1.5：新号冷启动（见附录 A）**

### 🎯 阶段 2：赛道重选与内容重做（第 3-6 周）

**目标：找到能涨粉的赛道，建立稳定的内容模型。**

#### 赛道建议：从"纯情感共鸣"转向"情感 + 实用干货"

我分析了你的数据和赛道特性，结论如下：

| 赛道 | 涨粉效率 | 你的现状 | 建议 |
|------|----------|----------|------|
| 纯情感共鸣 | ⭐ 慢（靠推荐，权重低） | 当前主战场 | 降为支线 |
| **情感 + 方法论** | ⭐⭐⭐⭐ 快（可搜索 + 可收藏） | 部分有 | **升为主线** |
| 职场/搞钱情绪 | ⭐⭐⭐⭐⭐ 最快 | 未涉及 | **新增** |
| 独居生存/生活技巧 | ⭐⭐⭐⭐ 快 | 有少量 | 扩充 |

**核心策略：用"解决问题型"内容吃搜索流量，用"情感共鸣"做粘性和追更。**

具体方向（优先级排序）：
1. **打工人情绪急救**：内耗自救 / 上下班崩溃瞬间 / 职场边界感 → 你的人设（31岁互联网打工人）天然适配
2. **关系实用指南**：从"为什么你会内耗"改成"3 个动作结束内耗"（方法论 > 纯共鸣）
3. **独居生存系列**：已有基础，扩充为"独居女生 100 个保命细节"（强收藏 = 高权重）

#### 任务 2.1 选题池重构
- [ ] 用 `generate_topics.py` 生成新选题，强制要求：
  - 搜索型问句占比 ≥50%（用户会主动搜的，如"经常内耗怎么办"）
  - 每个选题必须有**可收藏点**（清单/步骤/避雷）
- [ ] 90 个选题池保留情感共鸣类 30 个，新增实用方法论类 60 个

#### 任务 2.2 涨粉钩子设计（系统 + 人工）
35 篇 0 涨粉的核心原因之一：**没有任何一篇设计了"关注理由"**。

- [ ] 修改 `prompts/agent_writer.md`，结尾强制植入涨粉钩子（3 种模板轮换）：
  - **追更型**："明天更新：我用这 3 招治好了 3 年的内耗"
  - **合集型**："关注我，持续更新打工人自救指南"
  - **悬念型**："这件事，90% 的人都做错了（明天揭晓）"
- [ ] 启用 `series` 字段（当前 60/90 没填）：每个选题绑定系列，建立追更感

#### 任务 2.3 标题去模板化
当前标题太工整（"3步识别""5个信号"），改为：
- 口语化："我又因为内耗搞砸了一天"
- 痛点直击："经常累到不想说话？可能不是懒"
- 故事感："同事说了一句话，我突然不内耗了"

#### ✅ 阶段 2 通过门槛
- 单篇曝光稳定在 **3,000+**
- 出现 1-2 篇点赞 **200+** 的笔记
- **累计涨粉 500+**（即总粉到 1,400+）

## 3. 每周复盘机制（数据驱动）

每周日录入本周数据到 `data/performance.json`，用 `tabs/analytics.py` 看板分析：

- **看曝光趋势**：本周 vs 上周，是否在涨
- **看爆款率**：200+ 赞笔记占比
- **看涨粉率**：每千曝光涨几个粉（健康值 2-5）
- **看赛道分布**：哪个 pillar 的数据最好，加大投入

**连续 2 周数据下滑 → 立即召开"复盘会"，调整选题/标题/钩子。**

## 4. 风险提示

1. **1 万粉是高难度目标**：当前差距 170-400 倍，即使阶段 1-2 全部做对，阶段 3 也需要运气（爆款有随机性）。建议心理预期调整为 **5,000-8,000 粉**（仍是 5-8 倍增长）。
2. **不要为了频率牺牲质量**：阶段 2-3 即使日更，也要保证每篇都过审核（B 级以上）。系统已有熔断机制（连续 3 篇 C 级暂停），务必遵守。
3. **真人感是底线**：AI 辅助可以，但必须人工润色。小红书对 AI 内容的风控越来越严，被标记后很难恢复。
