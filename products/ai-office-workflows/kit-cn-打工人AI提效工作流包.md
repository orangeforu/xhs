# 打工人 AI 提效工作流包（中文版 v1.0）

> 给谁用：写周报、记纪要、做汇报、改简历的非技术岗打工人——运营/产品/行政/财务/HR。
> 用什么：任意对话式 AI（Kimi/豆包/ChatGPT/DeepSeek 都行），会粘贴就会用。
> 每条工作流 = 提示词 + 60 秒核查 + 翻车点。**核查部分才是本包的核心**——AI 编的从来不是内容，是因果。

---

## 通用防坑五条（先读这个，每条工作流都用到）

1. **因果是它最爱编的**：凡是"因为/导致/由于/影响了"开头的句子，都是它把两件无关的事缝成了一条逻辑链。发出去之前逐句过。
2. **安慰词必须带数字**："进展顺利""风险可控"后面没数字 = 给领导留话柄。要么删，要么补数。
3. **零缺口 = 它编了**：真实的数据、会议、一周工作必有缺口和没主的活。总结里一条没有，说明它"好心"替你补全了。
4. **抽查两处引用**：页码、数字、引用，随手核两个。AI 的引用 10-20% 是错的，错一处就该全查。
5. **AI 只分诊，人拍板**：涉及钱、承诺、日期、得罪人的事，AI 排序给你看，决定必须你自己做。

## 01 周报：40 分钟 → 10 分钟

**痛点**：周报不是写给领导看的，是写给你领导的领导看的——15 秒扫一眼，只找名字和数字。所以好周报故意写得"难看"：短句、数字、没有形容词。而整理一周的碎事才是最费时的——跳过它，那是 AI 的活。

**用法**：打开对话框，把这一周的原始碎片原样倒进去（聊天记录、待办勾选、文档改动、备忘录里半夜写的半句话，不要整理），然后把提示词贴在最上面：

```
你是我的周报助手。规则：
1. 分成三块：已完成 / 进行中 / 需要支持，每条不超过3行
2. 只保留有结果或有数字的事，"跟进""沟通""对齐"这类词全部删掉
3. 每条写成：做了什么 + 结果或数字 + 对谁有用
4. 不许补充我没说的事，不确定的地方标 [待确认]
5. 结尾最多列2条需要协调的事项
禁止出现：赋能、闭环、抓手、颗粒度、拉通、对齐颗粒度
```

**60 秒核查**：① 把每个 [待确认] 要么删掉要么补上；② **重点抓"编因果"**——比如你周二有个客户返工、周五有个项目延期，两件不相干的事，它会缝成"因客户返工导致项目延期"。逐句检查所有"因为/导致/影响了"。

**翻车点**：把小事写大（"推动跨部门协作"）；编因果链；凑下周计划（"持续跟进"删掉，没人看）。

## 02 会议纪要：只留决定、责任人、截止日

**痛点**：没人重读录音稿。纪要的全部价值 = 三个清单：定了什么、谁负责、什么时候交。**最有价值的其实是第四个清单：散会时还没找到主的活**——发回群里让领导指派，你悄悄成为全场最靠谱的人。

**用法**：录音转写/你的潦草笔记/群聊记录原样贴入：

```
你是我的会议纪要处理器。规则：
1. 只输出三部分：
   已决定——只有有人明确表示同意的才算，附一句原话，没原话不收录
   待认领——每条写：任务 + 一个具名负责人 + 一句话完成标准；
     没人说负责的，单独列入"无人认领，请领导指派"，不许猜一个
   截止时间——只收会上口头说过的日期，没说的写"未定"
2. 没形成结论的讨论全部删掉
3. 你推测（而不是听到）的内容标 [推测]
```

**60 秒核查**：**抓"编共识"**——"我觉得可以再看看"会被它写成"已决定再评估"。每条"已决定"必须有原话引文。另外：真实会议一定有没主的活，纪要里"无人认领"是空的 = 它替你圆场了。

---

## 03 进度同步：四行字，堵住"进展怎么样了？"

**痛点**：领导随时问"进展怎么样"不是要信息，是**看不见你在干什么产生的焦虑**。对付焦虑靠节奏，不靠秒回。固定频率发四行，比回得快管用十倍。

**用法**：把本周碎片倒进去（同 01），用这个提示词：

```
你是我的进度同步邮件写手。规则：
1. 固定四行格式：
   已完成：[1-2件，每件带数字]
   下一步：[1-2件，每件带日期]
   风险：[只写真实卡点，每个带"我需要什么才能解锁"]
   目前没有需要担心的：[一句真话]
2. 每个进度结论必须对应我给的材料；材料里没有的，动词降级
   （"启动了"不能写成"基本完成"）
3. 禁止出现无数字的安慰词："顺利""可控""稳步推进"
4. 我没给风险就写："暂无明显卡点，如有变化我会在[周几]前同步"——不许为了显得全面编一条
```

**60 秒核查**：把每个"已完成"的动词和你的原始材料对一遍——AI 会悄悄升级动词（启动→推进中→基本完成）。第四行是堵追问的杀手锏，但**必须是真话**，不是真话就删了别用。

## 04 长文档摘要：3 小时 → 25 分钟，专挖埋的坑

**痛点**：合同/政策/招标文件/供应商方案的摘要不是"缩短版"，是另一个产品：**有什么变化、哪里会咬人、周一干什么**。坑永远不在正文，在脚注、附注、和"但书"里。

**用法**：文档分块贴入（"第1部分/共4部分"），加一句身份："我是运营负责人，需要知道这文件让我们承担了什么义务。"

```
你是我的文件分析师。规则：
1. 输出四部分：
   白话说明——这份文件是什么，3句话，无术语
   影响什么——对我的角色/业务的具体影响
   埋坑清单——条件、例外、截止日、自动续约、违约金、依赖关系，
     尤其埋在脚注/附注/条款but书里的，每条附页码引用
   周一行动——最多3件下周真的要干的事
2. 每个结论必须带页码 [第X页]，没有页码不许说
3. 看着像模板条款但可能咬人的，也标出来 [疑似模板条款]
```

**60 秒核查**：**抽查两处页码引用**——AI 的页码 10-20% 是编的，两处全对才敢信其余。另外：一份百页文件的分析如果没有任何一条让你意外的"坑"，说明它偷懒只摘要了开头的执行摘要，重跑。

## 05 脏表格：AI 读乱账，你核算术

**痛点**：两小时从来不在 Excel 里，在"原始导出"到"能见人"之间。AI 是极好的**翻译层**（读乱数据），极差的**计算器**——分工明确就没问题。

**用法**：原始数据连表头原样贴入（混合日期格式、半空列、重名都别清理）：

```
你是我的数据清理助手。规则：
1. 先复述你对数据的理解：各列含义、行数、每行代表什么。然后停下来，
   等我确认后才能继续
2. 确认后输出：
   核心摘要——领导真正会问的5个数字
   异常项——看着不对的行（重复/不可能的值/缺口），原样引用
   格式问题——日期/名称/单位哪里不一致
3. 永远不许填补缺失值，哪怕看起来很明显，缺失项列入"缺口清单"
4. 每个摘要数字必须展示算式（= 42 + 17 = 59）
5. 不许自作主张去重，除非我确认那几行真是重复
```

**60 秒核查**：**亲手复算一个摘要数字**。对不上 = 它动过数据本身，所有数字全部作废重跑。另外真实数据必有缺口，"缺口清单"是空的 = 它替你补全了——那叫编数据。

## 06 催办：三个语气档，永远先发最软那档

**痛点**：催办死在语气选择，不是内容。你需要提前备好三档：轻轻提 / 认真提 / 抄送提。**永远发"够用的最软那档"**，白天不爽也忍住——第 4 天就发认真档不叫果断，叫后面半年都尴尬。

**用法**：只给它事实（催什么、哪天发的、卡住什么后果），**烦躁情绪不要写进去**（会污染三档全部语气）：

```
你是我的催办写手。规则：
1. 就 [事项]（[日期]发出）写三个版本：
   轻提——假设对方只是忘了（80%的情况就是忘了）
   认真提——第二次催，说明截止日和后果
   抄送提——客气、只摆事实、带抄送，零情绪
2. 每版最多3句：第一句=诉求+原发起日期；最后一句让对方回复成本最低
   （"回个'可以'就行"）
3. 禁用："如前所述""再次提醒""麻烦尽快""望周知"——这些在收件人眼里全是阴阳怪气
4. 只写事实。我输入里的情绪，三个版本都不许带
```

**60 秒核查**：**把"轻提"念出声**——听着刺就是"认真提"穿了件马甲，重写。抄送版当成"会被转发给更多人看"来检查，因为一定会被转发。

## 07 PPT 大纲：先脊柱，后骨头，最后才皮

**痛点**：AI 做 PPT 和差演讲者一个毛病：**堆要点、没主张**。规矩只有一条：每页有且只有一句 takeaway。先让 AI 给"脊柱"（每页一句话），脊柱单独读就是完整故事，才轮到往里填肉。

**用法**：

```
你是我的演示大纲生成器。规则：
1. 主题[X]，听众[Y——他们在乎什么]，页数[N]
2. 先只给"脊柱"：每页一句 takeaway，按顺序排。脊柱单独读完必须就是
   完整的故事。给完脊柱就停，等我确认
3. 我确认后，每页给：takeaway（15字内）+ 2-4条支撑要点 +
   一行"这页不讲什么"（防止范围蔓延）
4. 第1页直接放结论，不要放目录——领导听结论，不听目录
5. 一页一个观点，装不下就拆两页
6. 不许编数据撑场面，我没给数字的地方标 [缺数据]
```

**60 秒核查**：只读脊柱那几句——**连不成完整论证 = 这是个参观路线不是故事**，改脊柱，别急着排版。这就是先脊柱的意义：故事 60 秒审完，不用等两小时美化完才发现讲不通。

## 08 简历/述职：把"负责过"改写成"改变了什么"

**痛点**：弱 bullet 写职责，强 bullet 写**后果**。改写不是润色，是**找证据**：你"负责"的每件事背后都藏着一个数字（多少/多快/多久一次）。你对这些数字的记忆才是壁垒，AI 的词汇量不是。

**用法**：现有条目原样贴入（包括那些"参与了""协助了"的）：

```
你是我的简历条目编辑。规则：
1. 每条改写成：动词 + 做了什么 + 可量化结果 + 对谁有用
2. 不许发明数字。我没给数字的，写 [数字?]，并问我一句
   "大概多少/多快/多久一次？"
3. 禁用："负责""参与""协助""支持"——这些是岗位说明书不是成绩
4. 改写只能停留在我给的证据水平："负责月报"不许升级成"优化了汇报体系"
5. 每条输出格式：原句 → 改写 → 我还需要补什么数字
```

**60 秒核查**：**扫无数字的成就**——每条改写要么有真实数字，要么带 [数字?]。出现"听起来很强但两者都没有"的，就是 AI 超出你的证据给你升级了——面试官专戳最亮的那条，戳穿一条，全盘皆输。

## 09 预判领导追问：会议输在汇报后的 30 秒

**痛点**：向大领导汇报，输的从来不是汇报那几分钟，是**你以为讲完了的那 30 秒**——杀手问题全是你的内容自己招来的：没基线的数字、没背景的成绩、只提了一句没给量级的风险。好消息：你自己内容招来的问题，可以提前从内容里推出来。

**用法**：把你准备讲的内容原样贴入：

```
你是我的汇报预演教练。我在准备[越级汇报/经营分析会/向大领导汇报]。
对方只有15秒背景信息、高度怀疑、不打算客气。规则：
1. 像这个人一样攻击我的汇报，提出5个我最不想听到的问题，
   优先从我内容自己招来的点下手
2. 每个问题给：(a)为什么会问 (b)只用我材料里的事实组一句回答
   (c)会前我该补查什么
3. 指出我汇报里任何"会招来我答不上问题的点"，建议删掉或补上能拆弹的数字
```

**60 秒核查**：**5 个问题都好答 = 它在客气**，加一句"假设这位领导觉得我的工作无足轻重"重跑。问题必须是针对你内容的（"你说转化降了12%——基线是什么？"），全是模板题（"进度如何？""预算够吗？"）= 它没读你的材料，重跑。

## 10 消息分诊：立刻回 / 上报 / 缓一缓

**痛点**：消息多到窒息不是数量问题，是**没分拣**：该回的、该升级的、不用理的混成一堆。分拣才是工作量，回复反而是容易的。危险的分错方向永远是一种：**把"该拍板的"当成"聊两句的"**——钱、日期、承诺、投诉，都不是"顺手回一条"的事。

**用法**：消息原样贴入（多人多客户都行，保留署名）：

```
你是我的消息分诊助手。规则：
每条消息归入且仅归入一类：
  立刻回——事实性、我权限内、低风险。给我一句2句话草稿供修改
  需上报——涉及钱/承诺/日期/投诉/我无权决定的。说明它需要什么
    （审批/电话/领导介入），不许替我起草回复
  缓一缓——无截止日、无需决策的，归入[周几]统一处理
规则：
1. 拿不准"立刻回"还是"上报"时，一律上报——这里乐观一次就是真金白银
2. 每条消息引用触发光类的原句，让我能核对你的判断依据
3. "立刻回"的草稿永远不许承诺日期、价格、结果，需要的地方写 [待我拍板]
4. 客气话里藏截止日的（"月底前方便的话…"），不许归入缓一缓
```

**60 秒核查**：**扫"立刻回"堆里所有带钱/日期/承诺的**——AI 天生想"解决问题"，会把需要人拍板的消息顺手写了回复。有一条就算一条，全部升级到"需上报"。然后真的读一遍那些触发原句，这就是这个工作流可审计的原因：你核的是"为什么"，不只是"是什么"。

---

## 结尾：这套东西的用法心法

AI 负责把乱的东西变整齐，**你负责把假的挑出来**。每条工作流的"60 秒核查"就是挑假的那一步——10 条核查练熟，你会形成对所有 AI 输出的条件反射，那才是这个包真正的价值：不是 10 个提示词，是 10 副眼镜。
