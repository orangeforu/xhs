# 实测 02 会议纪要

## 人工核对点
- [ ] 『入库权限』只是『再看看』的讨论，是否被写成『已决定』（编共识陷阱）
- [ ] 『活动物料提前订』没人认领——是否进了『无人认领』而非被安给某人
- [ ] 『争取下周』是模糊日期——截止时间是否如实处理（未定/引用原话）而非擅自写成具体日期

## 工作流输出（最终轮）

```
已决定
- 入库权限事项下季度再看看。原话：刘总：“行，那先这样。”
- 发票事项由小王负责。原话：张经理：“好，小王负责发票。”

待认领
- 发票跟进：负责人：小王；完成标准：跟进发票事项（会上未明确具体完成标准）。
- 无人认领，请领导指派：
  - 活动物料提前订购；完成标准：提前订好活动物料，避免像上次一样临时抱佛脚。
  - 客户名单整理；完成标准：整理出客户名单。

截止时间
- 入库权限事项：下季度
- 发票跟进：未定
- 活动物料提前订购：未定
- 客户名单整理：下周
```

## 裸模型对照组（无工作流提示词）

```
**周会会议纪要（根据录音转写整理）**

**会议时间：** 今天（具体日期待补）  
**会议形式：** 周会  
**参会人员：** 刘总、张经理、小王、陈姐等（其他人员未具名）  
**记录来源：** 录音转写片段  

### 一、议定事项

1. **入库权限事项**
   - 张经理提出：入库权限的事下季度再看看。
   - 会上多人附和“可以”，刘总确认“先这样”。
   - **结论：** 暂不推进，下季度再评估/再议；具体牵头人待确认。

2. **发票事项**
   - 小王表示发票的事由自己跟进。
   - 张经理确认：小王负责发票。
   - **结论：** 发票事项由小王负责跟进，具体完成时间待确认。

3. **活动物料事项**
   - 刘总提醒：活动物料要提前订，避免像上次一样临时抱佛脚。
   - 会上未明确负责人，也无人接话。
   - **结论：** 需提前订购活动物料；负责人及截止时间待明确。

4. **客户名单事项**
   - 陈姐表示：争取下周把客户名单整理出来。
   - **结论：** 陈姐负责整理客户名单，目标为下周完成；具体截止日期待确认。

### 二、待办事项汇总

| 事项 | 负责人 | 时间要求 | 备注 |
|---|---|---|---|
| 入库权限评估 | 待确认 | 下季度再议 | 暂缓推进 |
| 发票跟进 | 小王 | 待确认 | 张经理已确认 |
| 活动物料提前订购 | 待明确 | 尽快/提前 | 会上未指定负责人 |
| 客户名单整理 | 陈姐 | 争取下周 | 具体日期待确认 |

### 三、待补充确认

- 活动物料订购的具体负责人、截止时间；
- 发票跟进的具体内容和完成时间；
- 客户名单“下周”的具体截止日期；
- 入库权限下季度由谁牵头跟进；
- 会议完整参会人员、日期、记录人。
```
