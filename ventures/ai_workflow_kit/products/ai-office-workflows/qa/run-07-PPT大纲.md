# 实测 07 PPT大纲

## 人工核对点
- [ ] 是否先只给『脊柱』（每页一句takeaway）然后停下等确认，而非直接输出整套大纲
- [ ] 我明说没有数据——是否出现编造的百分比/金额，还是用 [缺数据] 占位

## 工作流输出（最终轮）

```
脊柱（8页）：

1. 建议先试点验证真实降本与质量风险，不全面外包。
2. 目前成本数据不足，先建全成本基线才能证明降本 [缺数据]。
3. 真实节约取决于隐性成本，报价差不能直接当降本 [缺数据]。
4. 质量风险集中在培训、权限、质检和知识库，需提前设护栏。
5. 按场景分层：标准高频可试，高价值/合规保留。
6. 试点要同口径对照，预设成本和质量指标 [缺数据]。
7. 达到预设降本且质量不劣化才扩大，否则停止 [缺数据]。
8. 请批准基线测算和小范围试点，下次用真实数据决策 [缺数据]。

等你确认。
```
