# 今晚第一条：剪映 Windows 一对一操作卡

> 已确认：你用Windows电脑，模板创作者入口还没确认。今晚只做一条，不继续改底座、不做套装、不追热点。
> 本指南针对剪映专业版的通用剪辑流程。2026-10-29工具未列出可读取的剪映窗口，**尚未核对你的安装版本和实际按钮**；以下入口名称可能略有差别。看不到就按检查点发截图，不根据想象乱点。
> 一对一方式：你只做到当前检查点，发本页要求的截图；我根据你实际画面，只给下一小步。不要一次发十张图，也不必先把整本长手册读完。

## 先说清楚今晚要交付什么

**今晚制作目标：A0练习工程＋一条14秒竖屏MP4＋一次手动换图测试。** 如果已经有创作者入口，再继续验证平台模板配置；没有入口不阻止做这个小量学习样片。

必须区分三件事：

| 层级 | 完成后得到什么 | 能否称为“别人能剪同款的模板” |
|---|---|---|
| 工程样片 | 你电脑上能编辑、预览、导出的视频工程 | 不能 |
| 工程手动换图通过 | 同一工程换照片后时间和文字仍正常 | 仍不能；这只是编辑能力 |
| 原生模板替换通过 | 在官方创作者流程开放6个照片槽，用户视角套用通过 | 才能进一步提交模板审核；审核通过才算公开模板 |

**我不能在权限未确认前保证今晚发布成功，但会把第一条工程的制作步骤和卡住后的退路写清楚。** 别把导出MP4当成模板发布，也别把没有模板权限当成你不会剪辑。

### 今晚为什么先做A0，而不是完整卡A

A0：开场1秒＋6张照片各2秒＋收尾1秒＝14秒。无音乐、无转场、无缩放动画、无六宫格。

这是为第一次上手单独冻结的**练习版**，不是把[卡A正式规格](母版规格卡_20261028.md)偷偷降级。正式卡A的1.2秒开场、末张1.6秒、六宫格和五输入验收仍保留，等基础工程跑通后再升级。今晚不对外宣传、不上架，也不计入公开作品数。

打开 [练习素材文件夹](practice_20261029/)；需要单独保存时用 [练习素材压缩包](practice_20261029/first_template_practice.zip)。**先解压再导入，不在压缩包内部操作。**

| 文件 | 用途 |
|---|---|
| `00_background.png` | 米白背景；在开场和收尾各用一次 |
| `01_practice.png`～`06_practice.png` | 六张竖屏数字示意卡，分别代替照片1～6 |
| `07_replace_wide.png` | 横版“99”示意卡，最后测试替换 |
| `manifest.json` | 素材来源与尺寸说明，不导入剪映 |

它们是本地程序绘制的原创几何练习图，没有真人照片、第三方图片、音乐或字体。**这些数字卡不是周岁产品成品，也不是剪映工程。**

你已有6张自有照片也可以直接用，但建议第一遍先用数字卡，把“剪辑不熟”和“照片不好裁”分开。孩子照片不必上传给我；实际私人照片保存在你自己的私密目录，不放入会提交git的研究数据目录。

准备好计时：记下开始时间。计划约90—120分钟；累计到180分钟仍卡住，就停在检查点，不追加复杂效果。

## 1. 打开剪映，先确认我们在同一个界面（5分钟）

1. 用桌面或开始菜单中的剪映图标打开**剪映专业版**。
2. 不选“AI成片”“图文成片”或别人的模板，找普通剪辑的“开始创作／新建项目”入口。
3. 如果没有安装，先停在这里；只从[剪映官网](https://www.jianying.com/)获取正规Windows版本，安装由你本人确认。本轮没有替你下载或安装。
4. 如果要求登录、验证码、实名或订阅，由你本人处理；不要把密码、验证码或身份证发我。付费提示先取消，不购买。
5. 首页如果直接看到“模板／创作者”入口，只记“有”，不先钻进申请流程。没看到记“未确认”，不是“肯定没有”。

**检查点A：发一张剪映首页截图。** 遮住账号信息和不想展示的草稿名；附一句“Windows剪映，版本____，入口未确认”。不知道版本可以留空，不为了查版本卡住。

> 这张图用来核对按钮位置。若你正准备今晚再操作，读到这里就够；晚上从这里开始发图。

## 2. 新建一个空白工程（5分钟）

1. 点击普通“开始创作／新建项目”。不要打开已有重要草稿。
2. 如果顶部工程名可以改，改成：`JY_A0_first_20261029`。暂时找不到改名处，先继续，稍后回首页改。
3. 进入编辑器后，只认三个区域：**素材区**负责导入；**预览区**负责看画面；**底部时间线**负责排顺序和时间。
4. 在预览区附近找“比例／原始／16:9”等画布比例选项，设为 **9:16**。不要把“预览缩放百分比”当成画布比例。

**应该看到：**中间预览框是竖长形；下面时间线为空。

**卡住：**找不到比例时先导入竖图，在检查点B一起发编辑器全图；不要寻找本版没有的“项目设置”。

## 3. 导入素材，先做出第一秒（10分钟）

1. 素材区点“导入”，选择解压后的`00_background.png`及`01_practice.png`～`06_practice.png`。第一次不要导入横版99。
2. 导入成功后，素材区应有7张缩略图。**这里有缩略图不代表已经放上时间线。**
3. 把`00_background.png`从素材区拖到底部主轨最左端，让它从0秒开始。
4. 把这条背景片段缩短到 **1秒**。只拖片段的**右边缘**，不要拖片段中间；中间拖动是移动整条。

### 调时长只用这一套方法

- 先点选片段，再调它的右边缘；把时间线放大到能看见1秒、2秒等刻度。
- 本版如果有“时长／持续时间”输入框或右键选项，可以直接输入秒数；**没有就用拖边缘，不把找这个菜单当任务**。
- 拖动时看边缘提示的时长或结束位置；如果时间线磁吸能对齐播放头/相邻片段，就利用对齐。
- 时间码`00:00:01:00`通常表示1秒0帧，不是1.00的普通小数；若显示带帧格式，按当前项目实际帧率理解，今晚整秒边界不依赖小数换算。
- 看不清刻度或拖了仍不知道多长，发“选中该片段＋底部时间线”的截图，我按你的界面帮你定位。不要猜着改全局设置。

**检查点B：发编辑器截图。** 包含竖屏预览、素材区和完整底部时间线。应只有一条背景，范围约0～1秒。

## 4. 六张照片一张一张接上去（25分钟）

**不要一次把六张堆到同一时刻。每加一张就检查结束时间。**

1. 把`01_practice.png`拖到背景**右侧的同一主轨**，紧接背景，不要拖到上方另一条轨道。
2. 它应从1秒开始。把右边缘调到3秒，即本段2秒。
3. 按相同方法，依次接上02～06；每张都是2秒。
4. 最后再从素材区拖一次`00_background.png`到06右侧，作为1秒结尾。

顺序与时长按这张表，不凭感觉：

| 序号 | 主轨内容 | 开始 | 结束 | 本段时长 |
|---|---|---:|---:|---:|
| 1 | 00背景，开场 | 0秒 | 1秒 | 1秒 |
| 2 | 01照片占位 | 1秒 | 3秒 | 2秒 |
| 3 | 02照片占位 | 3秒 | 5秒 | 2秒 |
| 4 | 03照片占位 | 5秒 | 7秒 | 2秒 |
| 5 | 04照片占位 | 7秒 | 9秒 | 2秒 |
| 6 | 05照片占位 | 9秒 | 11秒 | 2秒 |
| 7 | 06照片占位 | 11秒 | 13秒 | 2秒 |
| 8 | 00背景，收尾 | 13秒 | 14秒 | 1秒 |

**应该看到：**同一主轨共8个片段，首尾是背景，中间01→06。片段间不留空隙，不叠到别的轨道。

卡点处理：

- 后面出现黑屏：检查相邻片段之间是否留空，或结尾后还有很远的片段。
- 图片同时显示：很可能放到了上方叠加轨道，先撤销刚才这一步，再拖到前一张右侧的主轨。
- 顺序不对：按文件名核对；不确定就发图，不要连续删除。
- 总长差几帧：先完成能播放的版本，再在检查点C微调到14秒；没有到14秒就如实记实际值，不称已按规格完成。

## 5. 先播放一次，不加效果（5分钟）

1. 把播放头移到0秒；点击预览区播放按钮。时间线已获得焦点时，也可以尝试空格播放/暂停。
2. 你应看到：空背景 → 01 → 02 → 03 → 04 → 05 → 06 → 空背景。
3. 检查比例是不是竖屏、数字是否完整、是否有黑帧。

**检查点C：发整条时间线截图，附“主轨8段，总长____秒”。** 如果此时卡住，先解决顺序和时长，不进入文字/动画。

> 通过这一步，第一条视频骨架已经成立。今晚不添加转场、关键帧、抠像、滤镜、六宫格和音乐。

## 6. 只加两条固定文字（15分钟）

### 开场：一岁一礼

1. 把播放头放到0秒。
2. 找顶部“文本／文字”分类，添加普通的“默认文本／新建文本”。不要选带VIP/会员标记的花字或模板。
3. 在文字编辑框输入：`一岁一礼`。
4. 预览里把文字拖到画面中间，使用清楚可读的深色，左右不出框。默认字体先只用于本地练习；正式发布前再核授权，不因“自带”就认定可商用。
5. 文字会在主轨上方成为单独一条。把它调到 **0～1秒**，不要盖到第1张照片。

### 收尾：愿你岁岁欢喜

1. 把播放头放到13秒，再新建一条普通文本。
2. 输入：`愿你岁岁欢喜`。
3. 把这条文字调到 **13～14秒**，居中，不超出片尾。

**应该看到：**主轨8段；文字轨2段，分别只覆盖开场和收尾。照片中间没有文字。

**卡住：**若字号/位置不好调，先保留默认大小，只做到可读、不溢出。若文字导致会员导出提示，换普通文本/默认字体，不付款解锁。

## 7. 保存并证明工程能重新打开（5分钟）

1. 暂停播放，确认工程名可识别。
2. 按软件可见的保存/返回首页方式保存。剪映可能自动保存，但**看到草稿能重新打开才算有证据**，不以猜测代替。
3. 从首页重新打开刚才的工程：素材无丢失、时间线仍在，才继续。
4. **不要移动或删除刚才导入的图片文件夹。** 工程可能引用原路径；MP4不是工程备份。

若返回时提示保存，由你本人选择保存。不要清缓存、删草稿或移动项目目录。

## 8. 先导出第一条MP4（10分钟）

1. 全片再播一次，确认01～06顺序与两段文字。
2. 找右上或界面可见的“导出”。这是导出视频，**不是发布模板**。
3. 若可选，设：MP4、1080p、30fps、默认/推荐码率；不要选收费AI增强、补帧或云服务。
4. 选择你自己能找到的本地文件夹，文件名：`JY_A0_preview_20261029.mp4`。
5. 完成后用系统播放器从头播放。不是只看“导出成功”的提示。

**检查点D：发本地播放器画面或导出结果截图，附“实际时长____、分辨率____、能否从头播到尾____”。** 不必上传含孩子隐私的视频。

卡住分支：

| 现象 | 现在只做什么 |
|---|---|
| 弹会员/素材付费 | 截图看具体被标记的功能，移除那个功能/换普通字体，不付款 |
| 导出不是竖屏 | 回第2步改画布比例，导出设置不能代替画布设置 |
| 时长多出一截 | 检查文字轨末端、空隙或远处遗留片段 |
| 源图丢失 | 放回原文件位置或用软件的重新链接素材功能；别重建一切 |
| 找不到导出按钮/导出报错 | 截当前完整窗口＋错误文字，停在这里；不装破解或不明插件 |

## 9. 再做一次手动换图测试（10分钟）

**先保住刚才的工程与导出。**

1. 如果首页草稿菜单有“复制／创建副本”，复制为`JY_A0_replace_test`再打开。没有该选项就先把工程截图发我，不在唯一原稿上盲删。
2. 在副本中导入`07_replace_wide.png`，它是横版“99”示意图。
3. 选中主轨中的**03照片片段（5～7秒）**。如果右键/素材操作区有“替换”，用它选横版99；若没有明确替换入口，先截图，不猜某个拖放动作一定会保留时长。
4. 替换后检查：仍是5～7秒、前后片段没移位、开场和收尾文字未改变。
5. 若横图被裁，选中该片段，在预览/右侧画面大小或缩放控制中调小，先让“99”和整张图完整。允许练习片出现留边，不为铺满裁掉主体。
6. 播放4～8秒，看02→99→04；再看首尾文字。

**完成记录：**“换图成功／找不到入口／换后时长变了／裁切异常”。这只验证工程编辑替换，**不是用户的原生模板槽位验收**。

如果今晚只到检查点D，也已经有可播放作品；替换未通过就如实保留未通过，不假装整个模板完成。

## 10. 创作者入口这一关，单独处理（最多10分钟定位）

今晚第一次作品出来后，再回首页/个人主页查看模板或创作者入口；普通编辑器里没有“发布模板”按钮并不奇怪。

- **找到申请入口但没权限**：截图申请要求及作品格式。这个A0只能作为准备样片，是否能用于申请以要求为准，不盲提交。
- **确实能创建/发布模板**：先发配置页截图。我再按实际界面带你确认**只有中间6张是可替换槽，背景和文字固定**；此时再谈模板审核，不把8个主轨片段全开放给用户。
- **没有找到/不确定**：停止找菜单，保留工程。按[执行手册步骤一](执行手册_从今天开始_20261028.md)走官方帮助或本人客服咨询；不买代开、不临时装插件。
- 付费权限M2与发布权限M1是两件事；没有M2不宣传付费，也不为了这条练习片开会员。

这10分钟只是今晚定位，不替代完整七项准入和两张工单。套装G1、跨平台账号、定价与发布排期都不在今晚这条练习工程里顺带完成。
